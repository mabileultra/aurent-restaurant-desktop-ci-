# Aurent Telegram bot — мини-приложение

Полноценный UX:
- главное меню (Reply Keyboard)
- поиск лекарств с карточками и наличием
- аптеки рядом
- избранное и история
- поддержка с категориями и номерами обращений

## Env

См. `.env.example` и корневой `.env`:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_SUPPORT_GROUP_ID`
- `TELEGRAM_BOT_API_TOKEN`
- `TELEGRAM_BOT_BACKEND_URL`
- `TELEGRAM_BOT_DATA_DIR` (по умолчанию `./data`)

## Команды

- `/start` — главное меню
- `/find` — поиск
- `/nearby` — аптеки
- `/favorites` — избранное
- `/history` — история
- `/support` — поддержка
- `/help` — о сервисе

## Заметки

- Расстояние в км и часы работы появятся после добавления координат/графика в магазины.
- Бронь и уведомления о цене — кнопки есть, backend-уведомления в следующем этапе.

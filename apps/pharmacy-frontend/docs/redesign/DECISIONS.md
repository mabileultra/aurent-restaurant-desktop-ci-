# Redesign Decisions Log

## Phase 0 (Audit)

1. **Docs path (`apps/pharmacy-frontend/docs/redesign/`)**: Placed `AUDIT.md`, `DECISIONS.md`, and `screenshots/` inside `apps/pharmacy-frontend/docs/redesign/` rather than root `docs/`, keeping all redesign artifacts scoped to the pharmacy frontend package.
2. **ESLint baseline**: `apps/pharmacy-frontend` currently has no `.eslintrc.cjs` (unlike `apps/web-frontend` and `apps/restaurant-frontend`), so `eslint src --ext .js,.jsx` fails with missing config. We will add a minimal `.eslintrc.cjs` matching `apps/web-frontend` in Phase 1 (or verify linting cleanly) and log it here.
3. **Print vs settings panels in `src/shelfLabelPrint/`**: `src/shelfLabelPrint/` mixes actual print DOM output (`ShelfLabelSheet.jsx`, `ShelfLabelBarcode.jsx`, `printShelfLabelDriver.js` — strictly out of scope) with admin settings UI (`ShelfLabelPrintModal.jsx`, `LabelTsplSettingsPanel.jsx`, `ShelfLabelPrintSettingsPanel.jsx`) that contain `dark:` and `violet-*`/`slate-*` classes. We keep print output untouched and will restyle only the modal/settings controls in Phase 5 without touching label rendering or print CSS.

## Phase 1 (Foundation)

1. **ESLint config (`.eslintrc.cjs`)**: Added minimal `.eslintrc.cjs` with `react` and `react-hooks` plugins and `react/jsx-uses-vars` enabled. Kept `react-hooks/rules-of-hooks` out of blocking errors for now because two pre-existing untouched files (`PlatformFilterMenu.jsx` and print module `useLabelPrintLayoutSettings.js`) have conditional hooks and business/print logic must not be altered during redesign.
2. **Self-hosted Inter Variable (`@fontsource-variable/inter`)**: Removed Google Fonts CDN import from `src/index.css` and imported `@fontsource-variable/inter` in `src/main.jsx`. Verified `cyrillic`, `cyrillic-ext`, `latin`, and `latin-ext` (including `U+02BB-02BC` for Uzbek `oʻ`/`gʻ`) woff2 bundles emit into `dist/assets/`.
3. **Token bridge during migration**: Defined RGB-channel Pharma Green tokens (`--color-primary-50..900`, `--color-canvas`, `--color-surface`, `--color-line`, `--color-line-strong`, `--color-ink*`, `--color-success/warning/danger/info*`) in `src/styles/tokens/colors.css` and exposed them in `tailwind.config.js` via `theme.extend.colors`. Mapped legacy `--color-brand*`, `--admin-*`, and `--pos-*` CSS variables to the new light tokens so unmigrated modules immediately shift off dark/deep-green gradients without breaking before Phases 2–5.
4. **Dark mode removal at root**: Removed `darkMode: 'class'` from `tailwind.config.js`, removed `AdminThemeSync.jsx` (`syncRootTheme()` now runs directly at boot in `main.jsx` and shell hooks), removed `syncRestaurantTheme`, `useAdminThemeStore`, `cashierTheme` state and `toggleCashierTheme` from `usePharmacyPosShell` / `PharmacyPosShell`, and locked `color-scheme: light` with static `<meta name="theme-color" content="#F6FAF7" />`. Per-component `dark:` utility classes will be removed across Phases 2–5.
5. **Component `@apply` layer (`src/styles/components/*.css`)**: Created `buttons.css`, `cards.css`, `forms.css`, `tables.css`, `badges.css`, `overlays.css`, and `navigation.css` using `ui-*` prefix inside `@layer components`, imported before `@tailwind base` in `src/index.css` to satisfy PostCSS `@import` ordering.
6. **Chart palette**: Added `src/config/chartPalette.js` with Pharma Green series, grid, axis, and typography constants for Recharts.

# Краткая инструкция для кассира — Aurent POS

Распечатайте или отправьте кассиру в Telegram.

---

## 1. Начало смены

1. Откройте **Aurent Cashier** (desktop) или кассу в браузере.
2. Войдите по **PIN** или логину.
3. Нажмите **«Открыть смену»** — укажите сумму в кассе (размен).
4. Дождитесь сообщения «Смена открыта».

## 2. Продажа

1. Отсканируйте штрихкод или найдите товар в списке.
2. Для **весового** товара — отсканируйте этикетку с весов или введите вес вручную.
3. Проверьте корзину → **Оплата**.
4. Выберите способ: наличные / карта / смешанная.
5. Выдайте чек покупателю.

## 3. Возврат

1. Меню → **Мои чеки** (или поиск по чеку).
2. Найдите чек → **Возврат** (полный или по позициям).
3. Подтвердите — остаток вернётся на склад.

## 4. Конец смены (Z-отчёт)

1. **Закрыть смену** / **Z-отчёт**.
2. Пересчитайте наличные в ящике.
3. Сверьте сумму в отчёте с фактом.
4. Передайте Z-отчёт администратору.

## 5. Нет интернета (desktop)

1. Продажи сохраняются **локально** — продолжайте работать.
2. Не закрывайте программу.
3. Когда сеть появится — данные **синхронизируются** сами.
4. Если смена не открывается офлайн — один раз откройте кассу **онлайн**, затем можно снова офлайн.

## 6. Частые проблемы

| Проблема | Что делать |
|----------|------------|
| Товар не находится | Проверьте штрихкод, попросите админа добавить товар |
| Не печатает чек | Настройки → Принтер, проверьте кабель |
| Ошибка при оплате | Повторите; если не помогло — звоните админу |
| Смена не открывается | Перезапустите программу, проверьте интернет |

## 7. Поддержка

Телефон и Telegram — на странице **«Поддержка»** в кассе или у администратора магазина.

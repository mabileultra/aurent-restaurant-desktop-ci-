# Чеклист безопасности кассира — Aurent POS

Проверка для администратора **перед запуском клиента** (5–10 минут).  
Выполняйте под учёткой **CASHIER** (не ADMIN).

---

## 5 запрещённых действий (должны давать 403 / «Access denied»)

| # | Действие | Как проверить | Ожидание |
|---|----------|---------------|----------|
| 1 | **Удалить товар** | API `DELETE /api/v1/products/{id}` или UI каталога | 403 Forbidden |
| 2 | **Изменить цену / остаток** | `PUT /products/{id}`, `PATCH /products/{id}/stock` | 403 |
| 3 | **Журнал движений товара** | `GET /products/{id}/lifecycle` | 403 |
| 4 | **Чужой магазин** | Продажа с `storeId` другой точки (не из назначенных кассиру) | 400 «You are not assigned to this store» |
| 5 | **Чужой чек** | `GET /sales/{id}` чека другого кассира | 400 «Access denied» |

---

## 5 разрешённых действий (должны работать)

| # | Действие | Ожидание |
|---|----------|----------|
| 1 | Открыть смену на **своём** магазине | OK |
| 2 | Продажа штучного товара | Чек, остаток −1 |
| 3 | Возврат **своего** чека | OK |
| 4 | Поиск товара по штрихкоду | OK |
| 5 | «Мои продажи» | Только свои чеки |

---

## Настройка в админке

1. Кассиру назначить **роль CASHIER** (не ADMIN).
2. В карточке пользователя указать **магазин(ы)** — без этого касса не откроет смену.
3. В «Доступах» включить только: `cashierPos`, `cashierSales`, `cashierOffline` (+ весы/ресторан при необходимости).
4. Перелогиниться на кассе после смены прав.

---

## Автоматическая проверка в CI

```bash
node scripts/check-cashier-security.mjs
```

Связанные политики в коде: `SaleAccessPolicy`, `CashierSaleSupport`, `@PreAuthorize` на контроллерах.
